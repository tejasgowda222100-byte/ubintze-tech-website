UBINTZE TECH WEBSITE

FILES
- index.html: website content
- style.css: design and responsive layout
- script.js: mobile navigation and footer year

PREVIEW
Open index.html in a web browser.

PUBLISH WITH GITHUB PAGES
1. Create a PUBLIC GitHub repository named ubintze-tech-website.
2. Extract this ZIP on your computer.
3. In the repository, choose Add file > Upload files.
4. Upload index.html, style.css, script.js, and README.txt directly to the repository root (not the ZIP file and not a nested folder).
5. Commit the changes.
6. Open Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Choose branch main and folder /(root), then Save.
9. Wait for GitHub Pages to publish the site and show its URL.

IMPORTANT
The contact email hello@ubintzetech.com is a placeholder. Replace it in index.html with a real email before publishing.
